# Witchr Agent Instructions

## Page Imagery Standard

All new Witchr page imagery must follow:

* /docs/witchr-visual-style.md
* /docs/witchr-image-generation.md

Do not invent a new visual style for individual pages.

Before planning or generating imagery for any new Witchr page:

1. Read both visual system documents.
2. Determine the correct Witchr image type for the page.
3. Create the page-specific image manifest.
4. Preserve the strict Witchr purple-and-black duotone visual identity.
5. Keep the page subject immediately recognizable.
6. Follow the image SEO and performance rules in the documentation.
7. If image generation is authorized for the task, use the native generate_image capability.
8. If image generation is not authorized, create the image manifest and generation prompt without inserting substitute stock imagery.

Do not alter existing live page visuals merely because these instructions exist.
